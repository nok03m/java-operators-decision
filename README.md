## 📖 About the Project

Understanding how to manipulate data with operators and control the flow of execution with decision structures are two foundational pillars of Java programming. This repository provides clean, well-commented code snippets and practical examples to master these core concepts.

---

## 🔍 Topics Covered

### 1. Java Operators
The repository covers the different categories of operators provided by Java:
* **Arithmetic Operators:** `+`, `-`, `*`, `/`, `%` (addition, subtraction, multiplication, division, modulus).
* **Relational Operators:** `==`, `!=`, `>`, `<`, `>=`, `<=` (comparing values).
* **Logical Operators:** `&&` (AND), `||` (OR), `!` (NOT) with short-circuit evaluation details.
* **Assignment Operators:** `=`, `+=`, `-=`, `*=`, `/=`, etc.
* **Unary Operators:** `++`, `--`, `+`, `-`, `!`
* **Ternary Operator:** `(condition) ? true_case : false_case`
* **Bitwise & Shift Operators:** `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`

### 2. Decision-Making Structures
Control flow mechanisms used to implement conditional logic in applications:
* `if` statement
* `if-else` statement
* Nested `if-else` statements
* `switch` statements (including modern switch expressions)

## ⚙️ Prerequisites

To run the code in this repository, ensure you have the following installed:
* **Java Development Kit (JDK)** version 8 or higher (JDK 17+ recommended).
* Any Java-compatible IDE (e.g., IntelliJ IDEA, Eclipse, VS Code) or command-line terminal.

## 🚀 Getting Started & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nok03m/java-operators-decision.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd java-operators-decision
   ```

3. **Compile and run any Java file via terminal:**
   ```bash
   javac Main.java
   java Main
   ```
   *(Alternatively, open the project folder in your favorite IDE and run files directly from the UI).*
